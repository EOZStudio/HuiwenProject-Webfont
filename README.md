# HuiwenProject-Webfont
本專案為匯文系列（Huiwen Project）的非官方woff2版，提供jsDelivr網址以便嵌入進CSS。

原作者：特里王（Terry Wang）
```
@font-face {
  font-family: "Huiwen-Zhengkai";
  font-display: swap;
  font-style: normal;
  font-weight: 400
  src: url("https://cdn.jsdelivr.net/gh/EOZStudio/HuiwenZhengkai-Webfont@main/匯文正楷.woff2") format("woff2");
}
