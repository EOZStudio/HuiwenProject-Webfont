# HuiwenProject-Webfont
本專案為匯文系列（Huiwen Project）的非官方woff2版，提供jsDelivr網址以便嵌入進CSS。

註：匯文明朝體GBK採用GitHub Pages網址，因檔案大小高於JsDelivr限制

原作者：特里王（Terry Wang）
```
@font-face {
  font-family: "Huiwen-Fangsong";
  font-display: swap;
  font-style: normal;
  src: url("https://cdn.jsdelivr.net/gh/EOZStudio/HuiwenProject-Webfont@main/匯文仿宋.woff2") format("woff2");
}

@font-face {
  font-family: "Huiwen-Mincho";
